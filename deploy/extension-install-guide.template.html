langfAIx 浏览器扩展：安装说明

扩展版本 {{VERSION}}

langfAIx 在网页的输入框里检查英文：拼写、语法和术语的问题会画上红色波浪线，点一下就能改。需要时可以让 AI 改写一句话，还可以查团队的中英对照术语表。

开始之前，准备好三样东西

  • Chrome 或 Edge 浏览器（平时自动更新的版本就可以）。
  • 连着服务器所在的网络，或者能连到它的 VPN。服务器只在内部网络里。
  • 你自己的 API key，是 sk- 开头的一长串。向给你这份说明的人要。每人一把，不要借给别人，也不要发到群里。
    没有 key 也能用拼写和语法检查，只是不能用 AI 改写，也不能查术语表。

安装（大约 3 分钟）

  1. 解压。右键 langfaix-extension-{{VERSION}}.zip，选 全部解压缩 (Extract All)，位置填 C:\langfAIx-extension，再按 提取 (Extract)。
    这个文件夹以后不能删，也不能挪地方，否则扩展会从浏览器里消失。所以不要解压在"下载"文件夹里。电脑不让在 C 盘建文件夹的话，换一个你不会去动的位置，并记住它。
  2. 打开扩展页面。在浏览器的地址栏输入 chrome://extensions（Edge 是 edge://extensions），按回车。
  3. 打开 Developer mode。中文界面叫"开发者模式"或"开发人员模式"。Chrome 的开关在页面右上角，Edge 的在左边那一栏。
  4. 按 Load unpacked。中文界面叫"加载已解压的扩展程序"或"加载解压缩的扩展"。选刚才的文件夹 C:\langfAIx-extension，也就是打开后直接能看到 manifest.json 的那一层。
  5. 填设置。设置页会自己打开，填这两栏：
    Server address：{{API_URL}}
    API key：贴上你的 key
    然后按 Save and test connection。下面出现 Connected 就装好了。
  6. 把图标放到工具栏上（建议）。点地址栏右边的拼图图标，在 langfAIx 那一行点图钉（Edge 是眼睛图标）。

试一下

  • 安装之前就开着的网页，先刷新一次，扩展才会在里面起作用。
  • 在任意网页的输入框里输入 This are a test sentense.，停一秒，出错的地方会出现红色波浪线。把鼠标停在线上，点建议就替换。
  • 或者在设置页最下面点 Open the test page，那里有各种输入框可以试。

怎么用

你看到的 是什么，怎么用
红色波浪线 拼写、语法或者术语的问题。鼠标停上去看建议，点一下替换。改错了按 Ctrl+Z 撤销。不想理它就点 Dismiss；是你认识的词（人名、产品名），点 Add to dictionary，以后在哪里都不再报。
淡紫色虚线 这句话也许可以写得更好。这个提示本身不调用 AI。鼠标停上去，点了 Improve with AI 才会把这一句交给 AI。
输入框右下角的小圆标 3 数字是问题的个数，绿色对勾是没有问题。点开之后可以：查术语（输入中文或英文都行，点结果就复制）；让 AI 改光标所在的那一句、选中的文字或者全部文字；开关团队术语表 (Use the team glossary)。
工具栏上的 langfAIx 图标 Glossary 页签查术语，Quick check 页签可以贴一段文字进去检查。

你打的字会去哪里

  • 拼写和语法检查是自动的。输入框里的文字会送到你们团队自己的服务器去检查，不经过任何外部的服务。
  • 密码、姓名、邮箱、电话、地址、搜索框这一类输入框不检查。这是程序按输入框的样子来判断的，不保证每一个都认得出来。
  • AI 只在你点了之后才运行，而且只送你点的那一句或那一段。这一部分会通过团队的账号送到 AI 服务商（例如 OpenAI）。每次用完，卡片上会显示花了多少，记在你的 key 名下。
  • 服务器不保存你检查的文字，也不写进日志。这是程序的设计，不是技术上的保证：能管理服务器的人，理论上可以改程序去记录。所以如果你不放心，请用下面的办法只在你选的网站上使用。

只在你选的网站上使用（建议）

默认它在所有网站的输入框里都会检查。你可以让浏览器只在指定的网站上运行它：

  1. 在扩展页面，按 langfAIx 卡片上的 Details（详细信息）。
  2. 找到 Site access（网站访问权限），选 On specific sites（在特定网站上），按 Add，一个一个加上你要用的网站。
  3. 再加上服务器的网站 {{API_HOST}}。不加的话，扩展连不上服务器，设置页的测试会失败。

以后更新

收到新的压缩包时：

  1. 解压到同一个文件夹 C:\langfAIx-extension，问要不要替换时选替换。
  2. 在扩展页面，按 langfAIx 那张卡片上的刷新按钮（圆形的箭头）。
  3. 把开着的网页刷新一次。

地址、key 和个人词典会保留。换了文件夹再加载，浏览器会当成另一个扩展，这些都要重来；个人词典可以先在设置页按 Export 存一份。

碰到问题

情况 先看这几样
打了错字却没有红线 这个网页在安装或更新之后刷新过吗？连着服务器所在的网络或 VPN 吗？在设置页按 Save and test connection 是不是 Connected？
另外有些地方是故意不检查的：上面说的密码、姓名、搜索那一类；只填一个词的单行输入框；写代码的地方。Google Docs 目前不支持。
浏览器提醒你关闭"开发者模式的扩展" 有的浏览器启动时会这样提醒。把提醒关掉就行，不要选停用。
AI 卡片显示 API key 或 model is not available 到设置页检查 key 有没有贴全、前后有没有多出空格。还是不行，或者这把 key 还没有开通模型，就找给你 key 的人。
扩展从浏览器里不见了 多半是文件夹被删了或者挪了。照"安装"重新做一遍。

术语表页面

想看整张术语表或者维护它，打开 {{ADMIN_URL}}。第一次用 API key 登录，页面会请你设名字和密码，以后用它们登录。要修改术语，需要管理员先把你设成 editor。
