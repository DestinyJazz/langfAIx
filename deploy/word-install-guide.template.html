langfAIx Word 插件：安装说明

版本 {{VERSION}} · Word 桌面版，Windows

langfAIx 在 Word 里检查英文：拼写、语法和术语的问题会画上红色波浪线，旁边的侧边栏列出你正在看的这几页的问题。需要时可以让 AI 改写一句话或者一段话，还可以查团队的中英对照术语表。

开始之前

  • Windows 上的 Microsoft 365 订阅版 Word。买断版（例如 Office 2021）用不了。版本 2502 或更新的会跟着你滚动的页面检查；旧一点的只检查光标所在的段落。
  • 连着服务器所在的网络或者能连到它的 VPN，并且电脑能上外网（插件要从微软那里加载一个文件）。
  • 你自己的 API key，sk- 开头的一长串，和浏览器扩展用的是同一把。没有 key 也能用拼写和语法检查，只是不能用 AI 改写，也不能查术语表。

安装（只做一次）

装在你自己这台电脑上，只对你这个 Windows 账号生效。不需要管理员权限。

  1. 解压。在 {{ZIP}} 上按右键，选 Extract All（全部解压缩）。解压到哪里都行。
  2. 关掉所有 Word 窗口。
  3. 运行安装。在解压出来的文件夹里双击 Install.cmd。黑色的窗口里出现 Installed langfAIx for Word 就是装好了，按任意键关掉它。
    Windows 可能先问你要不要运行这个文件：按 Run（运行）；如果是蓝色的提示，先点 More info（更多信息），再点 Run anyway（仍要运行）。
  4. 打开 Word。Home 页签里会多一个 Check text 按钮，点它，旁边会打开侧边栏。 没有这个按钮的话：点 Home > Add-ins > More Add-ins（有的版本是 Advanced），在 Developer Add-ins 下面点 langfAIx。
  5. 填 key。点侧边栏最下面的 Settings，在 API key 里贴上你的 key，按 Save。不用填服务器地址。

怎么用

侧边栏开着它才工作。打开之后什么都不用按：滚到哪一页，那一页就会被检查。

你看到的 是什么，怎么用
红色波浪线 拼写、语法或者术语的问题。鼠标停上去，Word 会弹出最多 3 个建议，点一个就换；点忽略就不再标它。
侧边栏里的卡片 同一处问题的说明和全部建议。点建议就改；Dismiss 是不理它；Add to dictionary 是"这个词我认识，以后别再标"；点卡片的空白处，文档会跳到那一处。
淡紫色的线，和 Could read better 的卡片 这句话也许可以写得更好。这个提示本身不调用 AI。点卡片上的 Improve with AI 才会把这一句交给 AI。不喜欢这种线可以在 Settings 里关掉。
Improve with AI 按钮 先把光标放在一句话里，或者选中一段文字，再点它。它会列出可以改哪几段，选了才会送出去。结果里删掉的字标红、新加的标蓝，下面写着花了多少。点 Accept 才会改到文档里，改错了按 Ctrl+Z。
查术语的输入框 输入中文或英文都行。点一个术语就复制，点 Insert 直接放到光标处。
Pause 暂时不检查新的页面，要用时再点 Resume。

你写的字会去哪里

  • 拼写和语法检查是自动的。你滚到的页面上的文字会送到你们团队自己的服务器去检查，不经过任何外部的服务。没滚到的页面不会送。
  • AI 只在你点了并且选了要改哪一段之后才运行，只送那一段。这一部分会通过团队的账号送到 AI 服务商（例如 OpenAI），花费记在你的 key 名下。
  • 服务器不保存你检查的文字，也不写进日志。这是程序的设计，不是技术上的保证：能管理服务器的人，理论上可以改程序去记录。
  • 波浪线不会存进文档，别人打开你的文档看不到它们。key 和个人词典只存在你这台电脑上。

碰到问题

情况 先看这几样
Word 里找不到 Check text 先照安装第 4 步到 Developer Add-ins 下面找。还是没有：关掉所有 Word 窗口，再双击一次 Install.cmd，然后打开 Word。
Install.cmd 运行不了，或者窗口里是红色的字 把窗口里的字拍下来，发给给你这份说明的人。有的受管理的电脑不允许运行这类文件。
侧边栏是空白的，或者一直在转 连着服务器所在的网络或 VPN 吗？电脑能上外网吗？关掉侧边栏再点一次 Check text。
顶上写着 Cannot reach the server 到服务器的网络或 VPN 断了。连上之后它会自己恢复，不用重开。
有的错没有被标出来 规则检查不是什么都抓得到。把光标放在那句话里，用 Improve with AI 让 AI 看一眼。
AI 说 key 没填或者被拒绝 到 Settings 里检查 key 有没有贴全。还是不行就找给你 key 的人。

以后有新版本时一般不用做什么，关掉 Word 再打开就是新的。只有收到新的压缩包时，才需要解压并再双击一次 Install.cmd。不想用了就双击 Uninstall.cmd。安装之后，解压出来的文件夹可以删掉。
